No telemetry. No tracking.

This version of Cornetta sends no usage data, uses no analytics and has no feedback server. Recordings and transcripts stay on your computer; audio goes to the transcription service you configure only when you start a transcription.

Updated 7 November 2026.

Recordings

They stay on your computer, in the Music › Cornetta folder. Cornetta does not upload them and does not send file names, device names or contacts to any server.

Transcription

You can choose Apple Speech on this Mac or one or more HTTP providers. With Apple Speech, available on macOS 26, recognition happens on the Mac and audio does not leave the computer; on first use macOS may download the language model without sending the recording. With an HTTP provider, when you press Transcribe or enable automatic transcription, the audio file is sent only to the selected provider. The default HTTP provider is http://127.0.0.1:8080/v1/audio/transcriptions: if it runs on this Mac, audio does not leave the computer.

The HTTP provider receives the audio file, its filename and the model, language and response_format fields. It does not receive the transcript, other recordings, app logs, contacts or device names. If you choose a service on another computer, that operator also receives your IP address: use HTTPS and a service you trust. Each provider has a separate API key: it stays in the macOS Keychain and is sent only to that provider as a Bearer token.

The Check service button sends a GET request to the selected HTTP provider's model list. It sends no audio and does not save the settings.

Usage data

There is no telemetry, installation identifier, analytics or automatic crash report. The app opens no background connections.

GitHub update check

One of the network connections is the one you start from the menu with Check for updates on GitHub…. At that moment the app downloads two static files from GitHub Pages: update/feed.json and its signature update/feed.json.sig. The request contains the app version and a normal User-Agent; it contains no audio, text or file names. GitHub sees your IP address and applies its own privacy policy.

The ECDSA P-256 signature is verified with a public key embedded in the app before the version is read. If the signature is invalid, Cornetta shows no update. It does not download or install updates automatically.

Feedback

The Feedback button opens a new public GitHub issue in your browser. Nothing is submitted automatically from the app: you write the text and decide whether to publish it. The issue is public and handled by GitHub.

The website

This is a static site. It uses no cookies, Plausible, Telegram or other analytics, and it does not count visits. The only network requests are the ones needed to load pages and images from the server hosting the site.

Other services

The external services used by the app are GitHub, for actions you choose, and the transcription service you configure. If the transcription service is on another computer, that provider receives the recording's audio when you start a transcription. If it is on your Mac, the audio stays on the Mac. There are no other services, telemetry or automatic reports.

Who maintains this version

This is an open-source fork maintained by VVG-web, based on the original project by Federico Nejrotti. For problems or questions, open a GitHub issue.
