One file, two voices, under your control.

Cornetta records the microphone and call audio on your computer, with no audio driver. The recording stays on your computer; audio goes to the transcription service only when you start a transcription.

  • Any app

    WhatsApp, FaceTime, Google Meet, Zoom, Teams, Slack, Discord, Skype or the browser. Nothing to configure.

  • Your voice and theirs

    Microphone and system audio become one .m4a file, with a limiter that prevents clipping when you speak at the same time.

  • On-demand transcription

    You choose the Whisper-compatible HTTP service, for example one running locally on 127.0.0.1. Audio leaves only when you press Transcribe or enable automatic transcription.

  • Recovery after a crash

    During a call Cornetta writes recoverable working files. If the app closes abruptly, the recording is recovered on the next launch.

  • Apple Silicon and Intel

    One universal app for macOS 14.4 or later. The Windows 10 and 11 version is in beta and installs without administrator rights.

  • Free and open source

    No subscription, no ads, no account. The code is public on GitHub under the MIT license.

No telemetry. No tracking.

This version sends no usage data, uses no analytics and has no feedback server.

  • Recordings

    They stay in a folder on your computer. Audio is sent only to the transcription service you configure, and only when you start a transcription.

  • Transcription

    Cornetta ships no speech model. The default is a service on this Mac; if you choose a remote one, the recording's audio is sent to that address over HTTPS. There is no background upload.

  • Update check

    Only when you choose “Check for updates on GitHub”. The app downloads a feed and its ECDSA signature from GitHub Pages, verifies the signature, and only then reads the version. The request contains no audio, text or file names. Cornetta does not install updates automatically.

  • Feedback

    The button opens a public GitHub issue in your browser. There is no automatic submission and the app collects nothing.

  • No cookies

    This is a static site: no cookies, Plausible, Telegram or other analytics services.

    Open the releases page, download the DMG and drag Cornetta into Applications.

    macOS blocks apps that are not notarized. Open System Settings › Privacy & Security and click Open Anyway.

  3. Grant two permissions

    On the first recording allow Microphone and System Audio Recording.

Questions

Is Cornetta free?

Yes. Free, with no account, no subscription and no ads.

Which apps does it work with?

Any app that uses your computer's microphone and audio: WhatsApp, FaceTime, Google Meet, Zoom, Microsoft Teams, Slack, Discord, Skype and calls in the browser.

Does Cornetta collect data?

No. This version has no telemetry, analytics, cookies or feedback server. Connections are only the ones you start: the manual GitHub release check, opening a GitHub issue and transcription.

Audio goes only to the transcription service you configure, and only when you press Transcribe or enable automatic transcription. The default is a service on this Mac.

Are updates automatic?

No. Choose Check for updates on GitHub… from the menu: Cornetta downloads a signed feed from GitHub Pages, verifies its ECDSA P-256 signature with the public key embedded in the app, compares the version and, if there is a new one, opens the GitHub page. It does not download or install anything automatically.

Where are recordings saved?

In Music › Cornetta, as .m4a files (AAC, 48 kHz, stereo) named with date and time. They stay on your computer.

Does transcription use the internet?

It depends on the service you configure. The default is http://127.0.0.1:8080/v1/audio/transcriptions: if the service runs on this Mac, audio does not leave the computer. If you choose a service on another computer, the recording's audio is sent there only when you start a transcription. Cornetta ships no speech model and contacts nothing in the background.

How do I configure transcription?

Open Transcription settings… from the handset menu. Paste the OpenAI-compatible base URL, for example https://api.example.com/v1, then the model, language and API key. Check service verifies connectivity and the model without sending audio. The service is not included: the default is a server on this Mac. Audio leaves only when you press Transcribe or enable automatic transcription.

Is it legal to record a call?

It depends on where you live. In Italy and other one-party-consent places you may record a conversation you take part in for personal use; sharing it without consent is not allowed. Other countries and some US states require everyone's consent. Check your local law before recording.

Does it work on iPhone or Android?

No. iOS gives no app access to call audio, and Android blocks it for regular apps since Android 10. Cornetta runs on your computer.

Why does macOS say it cannot verify the developer?

This fork does not have a notarized Apple signature. On first launch open System Settings › Privacy & Security and click Open Anyway. You only do this once.
